## 왜 기록하는가

공부할 때는 이해한 것 같아도, 시간이 지난 뒤 다시 설명하려면 막히는 부분이 있습니다. 결과만 남기면 왜 그 방법을 선택했는지, 어디에서 막혔는지도 잊기 쉽습니다.

Knights Frontier 3기의 첫 미션을 계기로 이 블로그를 시작합니다. 잘 정리된 정답만 모으기보다, 질문에서 출발해 직접 확인하고 이해해 가는 과정을 남기려 합니다.

## 하나의 기록에 남기고 싶은 것

1. **질문과 배경**: 무엇이 궁금했고, 어떤 상황에서 문제가 생겼는가
2. **확인 과정**: 어떤 자료를 읽고, 어떤 환경에서 무엇을 확인했는가
3. **결과와 근거**: 실제로 관찰한 결과는 무엇이고, 어디까지 확인했는가
4. **남은 의문**: 아직 모르는 부분과 다음에 확인할 것은 무엇인가

실습이 잘되지 않았다면 그 이유도 기록합니다. 다른 자료를 참고했다면 원문을 연결하고, 제 해석과 원문의 내용을 구분하겠습니다.

## 여섯 개의 보관함

개발, CTF/Wargame, Bug Bounty, 블로그/기술문서, 논문/컨퍼런스, 공모전/자격증으로 기록을 나눕니다.

아직 글이 없는 카테고리는 앞으로 채워갈 공간입니다. 하지 않은 활동을 채워 넣기보다, 실제로 공부하고 확인한 만큼 하나씩 쌓으려 합니다.

## GitHub Pages로 시작하기

이 블로그는 GitHub 저장소에 있는 파일을 정적 웹사이트로 게시하는 **GitHub Pages**를 사용합니다. 글은 마크다운 파일로 작성하고, 변경 사항을 저장소에 반영하면 사이트를 다시 빌드해 게시합니다.

플랫폼의 사용법은 [GitHub Pages 공식 문서](https://docs.github.com/en/pages)와 [Jekyll로 글 작성하기](https://jekyllrb.com/docs/posts/)에서 확인할 수 있습니다.

이 첫 글을 시작으로, 나중의 제가 다시 읽고 이해할 수 있는 노트를 만들어 가겠습니다.
